# AI Usage / AI 使用说明

## What was AI-generated

- The initial drafts of all GDScript sources in this addon (`plugin.gd`, `context_menu.gd`,
  `scene_tree_menu_hook.gd`, `import_dialog.gd`, `sprite_frames_converter.gd`, `exporter.gd`,
  `node_finder.gd`, `i18n.gd`) were generated by an AI coding assistant (CodeBuddy / Claude-family
  model) from requirements supplied by the human author.
- The first drafts of the built-in Chinese and English UI strings and of `README.md` were also
  AI-generated.

## What the human author did

- Designed the feature set and workflow (context-menu entry, import dialog, batch export, undo).
- Reviewed, debugged and rewrote parts of the generated code inside the Godot 4.7 editor, including
  the scene-tree popup-menu injection, the deferred popup workaround, the `EditorUndoRedoManager`
  snapshot/restore logic, and the Godot 4.7 breaking-change fixes (`AnimatedSprite2D.playing`
  removal, `TreeItem` cell modes).
- Tested every feature manually in the editor and verified the exported animations, overwrite and
  batch behaviours.

## Not generated by AI

- No AI-generated art, audio, fonts or other media assets are included in this addon. The addon
  ships code, text and one plain-text license file only.

## 中文说明

- 本插件全部 GDScript 源码、内建中英文案与 README 初稿由 AI 编码助手（CodeBuddy）根据作者提出的需求生成。

  延迟弹窗处理、UndoRedo 快照回滚、4.7 破坏性 API 变更适配等），并逐一手工验证功能。
